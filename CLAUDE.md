# Runner Docs

This is the Runner documentation site (Mintlify). Pages are MDX files in `docs/`.

## Writing voice

All user-facing content must follow `docs/STYLE_GUIDE.md`. Read it before writing or editing any docs page.

Key rules:
- No em dashes. Use periods or commas.
- No corporate jargon or AI-sounding phrases.
- Write like a real person. Conversational, direct, varied sentence length.
- Short punchy lines mixed with longer explanatory ones.
- Trust the reader. Don't over-explain.

## Commands

- `mint dev` to preview locally
- `mint broken-links` to check links
