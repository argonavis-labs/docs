# Runner Docs

This is the Runner documentation site (Mintlify). Pages are MDX files organized in folders at the repo root (`get-started/`, `using-runner/`, `runners/`, `connections/`, `workflows/`, `tips/`, `use-cases/`, `legacy/`).

Runner is web-first at app.runner.now (v2). Terminology: a "Runner" is an always-on scheduled automation, "Workflows" are /slug instructions (formerly Skills), "Projects" replace workspaces. Full glossary in `AGENTS.md`.

## Writing voice

All user-facing content must follow `STYLE_GUIDE.md`. The voice is Kent's, built from his blog at [ewakened.com](https://ewakened.com). Read the style guide before writing or editing any docs page.

Key rules:
- No em dashes. Use periods or commas.
- No corporate jargon or AI-sounding phrases.
- Write like a real person. Conversational, direct, varied sentence length.
- Short punchy lines mixed with longer explanatory ones.
- Open with the specific thing, no preamble.
- Ask the reader's question, then answer it. "Why the difference? Simply cost."
- Be specific. Real numbers, real times, real app names.
- Trust the reader. Don't over-explain.
