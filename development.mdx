<Info>
  **Prerequisites**:
  - Node.js 19 or higher
  - This docs repository checked out locally
</Info>

This page is for docs contributors. It covers the local workflow for this Mintlify site.

<Steps>
<Step title="Install the Mintlify CLI">

```bash
npm i -g mint
```
</Step>

<Step title="Preview locally">

From the docs repo root, run:

```bash
mint dev
```

A local preview will be available at `http://localhost:3000`.

</Step>

<Step title="Check for broken links">

```bash
mint broken-links
```

</Step>
</Steps>

## Project files

- `docs.json` controls branding, navigation, and site-level settings.
- `*.mdx` files hold the page content.
- `images/runner-logo.png` is the logo asset used by the site.

## Custom ports

Mintlify uses port 3000 by default. To run on another port, use `--port`:

```bash
mint dev --port 3333
```

If port 3000 is already in use, Mintlify will try the next one:

```md
Port 3000 is already in use. Trying 3001 instead.
```
