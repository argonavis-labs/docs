title: "Heartbeat and Daily Brief"
description: "Set up the two built-in Runners: a morning brief and a twice-daily check for messages that need a reply."
---

Runner ships with two built-in Runners. Both start paused.

| Runner | Job | What waits for you |
|--------|-----|--------------------|
| **Daily Brief** | Your morning attention brief | The priorities and decisions that need you today |
| **Heartbeat** | Checks twice each weekday for messages that need a reply | Replies and decisions that still need a person |

Test them one at a time. It's easier to see what each one adds, and you won't create three versions of the same morning update. If you already built a Personal Assistant, check for overlap before turning on either schedule.

## Daily Brief

Daily Brief is scheduled for 8am every day in your timezone. It reads your calendar, inbox, and supported connected apps, then writes one update about what needs you today.

The stock prompt only reads from your connected apps. Its result appears in a new session, and it asks Runner to email you when it's ready. Email delivery depends on **Settings**, then **Notifications**, including the daily limit.

To test it:

1. Open **Runners**, then **Daily Brief**.
2. Review the prompt, schedule, and timezone.
3. Click **Run now**.
4. Read the result in the new session.
5. Turn on **Status** only if you want the daily schedule.

Change the prompt when you want a different brief. Be specific: *"Lead with anything from investors. Skip newsletter summaries."*

## Heartbeat

Heartbeat runs at 7am and 4pm on weekdays in your timezone. It checks connected communication channels and sorts the result into:

- **Needs you.** Something is waiting on a decision or reply.
- **Drafted.** A proposed reply is ready for review.
- **Heads-up.** Worth knowing, but no action is needed yet.
- **Could not check.** Runner couldn't reach a source.

When the relevant write tools are on **Ask**, the stock prompt can stage up to three **Action Cards** per run. If nothing needs you, it gives you one line and stops.

## Permissions for built-in Runners

Heartbeat and Daily Brief don't have their own **Tool permissions** section. They use the settings on each account under **Connected Apps**.

If you want every outward write to wait for review, keep those tools on **Ask**. **Ask** stages an **Action Card**, **Allow** acts without asking, and **Off** blocks the tool.

[Review tool permissions →](/connections/tool-permissions)

## What carries into the next run

Each built-in run starts in a separate session. It can use Personal Memory, but it doesn't automatically receive the previous run's output.

If a durable preference matters tomorrow, put it in Personal Memory or the saved Runner prompt.
