Each Runner is an AI teammate with one clear job. One follows proposals every morning. Another checks vendor invoices every Friday. Another gets your day in order at 9am.

They handle repeatable work across your connected apps and the cloud browser. You stay focused on judgment, relationships, creative decisions, and the work only you can do.

Use a session to brief a Runner, check a result, or improve the saved prompt. The scheduled work keeps running after you close the browser.

## Build the team one job at a time

Start with one recurring job you can measure. Get it working, then add another Runner.

**Write the job.** A Runner's saved prompt says what to check, how to decide, when to stop, and what a useful result contains.

**Connect the sources.** Connected apps and the cloud browser are how the work gets done. You connect the accounts, set tool permissions, and name the sources each job should use.

**Set the schedule.** Every weekday at 8am. Friday at 4pm. The first day of each month. Each run starts in a separate session and keeps going in the cloud after you close the browser.

**Set the review point.** **On** lets Runner read. **Ask** stages an **Action Card** for review. **Allow** acts without asking. **Off** blocks the tool unless a user-created Runner has its own override.

**Make the job last.** Runner keeps the saved prompt, schedule, Project, intelligence setting, and any Runner-specific tool permission overrides. Previous results don't carry automatically. Put rules for every run in the saved prompt. Use Project context for background.

<Info>
  Each Runner owns its own job. Runners don't automatically hand work to one another or receive another Runner's output. You decide how the team fits together.
</Info>
