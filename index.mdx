Runner turns repeatable work into a system that keeps running.

Connect the apps where the work lives. Explain the outcome, rules, and review points. Put it on a schedule. Runner handles the next run in the cloud, even after you close your laptop.

You can still chat with Runner whenever you want. That's how you give it work and improve what it does. The bigger payoff comes when a useful process runs again tomorrow without another prompt.

Start with a Personal Assistant. Then go after the work that brings in revenue, cuts costs, or keeps a customer promise from slipping.

## Build work that keeps running

A useful answer saves five minutes. A useful Runner can check every weekday for proposals waiting on a reply, invoices that don't match an agreement, or projects missing an owner.

That's the difference. You're not collecting prompts. You're building recurring work.

**Across your tools.** Runner reads the connected apps you choose and can use its cloud browser for work that still lives on a website.

**On a schedule.** A Runner is a saved prompt with a schedule. Each run starts in a separate session and keeps going in the cloud after you close the browser.

**When a fixed rule isn't enough.** Tell Runner what to check, how to decide, when to stop, and what the result should contain. It can bring the pieces together instead of following one brittle if-then branch.

**A person where it matters.** **On** lets Runner read. **Ask** stages an **Action Card** for review. **Allow** acts without asking. **Off** blocks the tool unless a user-created Runner has its own override.

**What carries forward.** Runner keeps the saved prompt, schedule, Project, intelligence setting, and any Runner-specific tool permission overrides. Previous results don't carry automatically. Put rules for every run in the prompt or Project.
