## Runner doesn't suggest. It finishes.

You can ask ChatGPT to write you an email. But it can't check your calendar before suggesting times, look up the email thread for context, or send the reply when you're done.

Runner can. It's connected to your actual apps, so it doesn't just think about your work. It does your work.

And now it doesn't stop when you do.

**Always on.** Runner keeps working in the cloud after you close the browser. Send a task and close your laptop. Dictate a voice note before boarding a flight. Check the result when you land.

**Everywhere you are.** Phone, iPad, laptop, desktop. Any browser. Your sessions sync across all of them. Need old context? Ask Runner to read another active session you own and use it here. It can't send a message into or resume that other session.

**Runners.** Put one prompt on a schedule. Each run starts in a separate session and can use Personal Memory and Project context, but it doesn't automatically receive the previous run's output.

**Choose the intelligence.** Sessions offer **Auto**, **Normal**, and **Ultra**. New sessions start on **Normal** unless you change the device preference. Scheduled Runners use **Normal** or **Ultra**, not **Auto**.

**You set the rules.** **On** lets Runner read. **Ask** stages an **Action Card** for review. **Allow** acts without asking. **Off** blocks the tool unless a user-created Runner has its own override.
