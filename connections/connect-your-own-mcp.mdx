<Warning>
  This page is for technical users who want to connect custom tools and services. If you're looking to connect Gmail, Calendar, Slack, or other popular apps, head to [Connect your apps](/get-started/connecting-accounts) instead.
</Warning>

Runner supports the Model Context Protocol, so if you have your own MCP server (internal tools, a vendor's server, something you built last weekend), you can plug it straight in. Its tools show up alongside your connected apps, with the same [per-tool permission controls](/connections/tool-permissions) as everything else.

Because Runner runs on a virtual computer in the cloud, custom servers are remote: HTTP or SSE endpoints reachable over the internet.

<Note>
  Coming from Runner Desktop? The `mcp.json` file and local `stdio` servers were a v1 feature. On the web you add servers through the UI instead, and they follow you to every device.
</Note>

## Add a custom MCP server

<Steps>
  <Step title="Open Connected Apps">
    Scroll past the app catalog to the custom section and choose **Custom MCP**.
  </Step>
  <Step title="Point it at your server">
    Enter the full MCP endpoint URL, including the `/mcp` or `/sse` path if your server requires it. If the server needs auth, add your bearer token or auth header here. Runner stores it securely and sends it with every request.
  </Step>
  <Step title="Set the permissions">
    Once connected, the server's tools appear in its **Tools** section like any other app. Decide what each one can do: On, Allow, Ask, or Off. For anything that writes, start with Ask.
  </Step>
</Steps>

To remove a server later, open it in Connected Apps and click **Remove server**.

## Or just ask Runner

You don't have to click through anything. Tell Runner what you want to connect:

<CodeGroup>
```text Remote server
Connect my Notion MCP server at https://mcp.notion.com/mcp
```

```text With auth
Connect a remote MCP server at https://example.com/mcp with bearer token abc123
```
</CodeGroup>

## No MCP server? Use Custom API

If the service you want has a REST API but no MCP server, choose **Custom API** in Connected Apps instead. Point Runner at the API and it can call it on your behalf, with the same permission controls.

## Troubleshooting

- If the server won't connect, confirm you used the full MCP endpoint URL, not just the domain.
- If requests fail with auth errors, the token belongs in the connection's auth settings, not in the URL.
- If new tools don't show up in an existing session, start a new session. Fresh sessions pick up the latest tool list.
