## Get started in four steps

Use this guide to get Runner ready for real work.

<Steps>
  <Step title="Install Runner">
    Download the desktop app from [runner.now](https://runner.now) and launch it.
  </Step>
  <Step title="Connect a model">
    Choose the model connection you want to use. Runner supports multiple connection types, so use the one that fits your setup.
  </Step>
  <Step title="Create a workspace">
    Create a workspace for the project, team, or client you want to work in. Each workspace keeps its own conversations, connections, and local settings.
  </Step>
  <Step title="Add context">
    Connect a managed app from **Connected Apps**, add a local folder, or bring in your own MCP server with [`mcp.json`](/connections/connect-your-own-mcp).
  </Step>
</Steps>
